# Phase IIb external scientific review preparation

No humans have been contacted or recruited, and no independent scientific
ratings or approvals have occurred. This directory contains preparation
artifacts, not secret labels or evidence of expert qualification.

The main distributable is `prepared_v1/reviewer_package.zip`. It includes all
32 historical cases plus all 12 added cases in mixed order, with source
provenance and archived artifacts, a neutral rubric, 132 blank forms for two
domain scientists and a statistical reviewer per case, and an exposure/conflict
declaration. Including all historical items avoids giving reviewers a package
selected only from the eleven author-labeled empirical positives. Provisional
answers, internal pair roles, original task IDs, splits, model identity, and
correctness aggregates do not appear as packet metadata.

`prepared_v1/internal/` is administrative material and **not** part of the ZIP.
It contains packet mappings and an internal priority plan, not a protected
database. The shared workspace and public references preclude a secret-holdout
claim. A coordinator must check prior reference exposure, candidate identity cues,
source rights/completeness, conflicts, consent and authorization before any
external distribution. Source or candidate text is not automatically redacted;
legitimate source identities are intentionally retained. Old labels are not
changed by assembling review materials.

The external brief is `docs/phase-iib/external_review_brief.md`, and the construct
and novelty audit is `docs/phase-iib/methodology_audit.md`. The additional
explanation-faithfulness literature retrievals are documented in
`method_literature_registry.json`; full article text stays in ignored local
cache. Existing Phase II literature records remain unchanged.

The reviewed ZIP has 39 members, 44 packets and 132 blank forms. A manifest
checks every member's bytes; its wrapper hash is
`b5f1a13e05eaea64e91ea03c961645909fd546a8548eaaa3f5d45e430a8c9c5f`.
A fresh repeat was byte-identical. Eleven tests exercise gold/identity field
filtering, source checksum/right retention, source-directory admission,
unregistered/escaping sources, blank forms, candidate text preservation, missing
outcomes, duplicate IDs/keys, and ZIP integrity. None establishes scientific
truth or successful human blinding.

Use `scripts/build_phase2b_review.py` for a fresh preparation. The command refuses
existing outputs and paths outside SVB. Optional actual-candidate records are
exported only as raw response text and generation state for the chosen A/B/C task
and evidence condition. Missing outputs are preserved. Do not distribute an
answer-quality package as if it were an independent reference-review packet.
