# Bound correctness is different from decision usefulness

This study uses real local FoldBounds CLI computations and independent exact
finite-model references. It asks whether correct probability bounds can support
the concrete decision “is P at least t?” at a specified computational setting.
Correct enclosure, interval tightness, decision coverage, decision correctness,
and wall time are reported separately. These are model-relative decisions,
not physical protein predictions, therapy decisions, or biological validation.

## Protocol, independence, and execution

The protocol was frozen before subject execution in
`data/v0.3.0/bound_utility_protocol.json`, SHA-256
`edc6ecc4fb8149e27927e4d6f627ce76ee98025a41fca5a2a961d62af8a5341c`.
Its digest is checked on execution. All references are calculated before any
subject call using the independently written SVB anchored self-avoiding-walk
enumerator, direct nonadjacent contact counts, and exact `Fraction` weights.
The program checks the known anchored path counts 543, 1479 and 4067 for
lengths 8, 9 and 10. No subject result supplies a reference probability.

There are eight sequence/q/event-threshold families. Six have nontrivial
contact events, varying q across 1, 5/4, 3/2, 2, 5/2 and 3. Two transparent
controls use an impossible event (all-polar sequence, at least one H–H contact)
and a certain event (contact count at least zero). Each family runs four
predeclared configurations, for **32 total actual CLI calls**:

| Configuration | Frontier depth | Additional existing options |
|---|---:|---|
| Shallow | 2 | Baseline certificate |
| Moderate | 6 | Baseline certificate |
| Enriched | 4 | Lookahead 2, matching, memory-4 transfer, terminal conditioning, witness budget 128, monotone lower masses |
| Full | Sequence length | Baseline complete enumeration |

The enriched setting deliberately adds several existing mechanisms at once.
It is a configuration comparison, not an ablation identifying the contribution
of any individual mechanism. It spends work beyond the nominal frontier depth;
depth alone is not a computational-budget measure.

For each probability interval, predeclared decision thresholds are
0, 1/100, 1/4, 1/2, 3/4, 99/100 and 1, plus the exact independent reference
probability as an equality stress test. Exact duplicates are removed. This
produces 248 related threshold observations: 62 per configuration. The equality
threshold is generated by a fixed rule before observing the subject, not tuned
to its failures. Nevertheless, these are deliberately selected model decisions,
not samples from an application workload or hidden testing distribution.

Every probability enclosure and partition enclosure is checked against exact
arithmetic. Each definite decision is checked separately against the reference
classification P>=t. Full depth is additionally required to give exact endpoint
equality. An invalid enclosure is a failure even if the sampled decisions
happen to be correct. A wrong definite decision is a failure even if another
case passes. Execution errors and unsupported interfaces remain explicit and
retain their expected decision rows in the denominator.

## Elementary guarantee and endpoint semantics

Assume a valid admitted interval 0<=L<=P<=U<=1 and a threshold 0<=t<=1.
The decision rule is:

- **Yes** if L>=t.
- **No** if U<t.
- **Undecided** otherwise.

**Conditional safety proposition.** Every definite decision from this rule
agrees with the target proposition P>=t.

**Proof.** A yes decision has P>=L>=t, so the target holds. A no decision has
P<=U<t, so the target is false. The two conditions cannot both hold because
L<=U would give t<=L<=U<t. These exhaust the definite decisions. The proof
assumes the enclosure is valid; it does not prove that a particular algorithm,
certificate parser, physical model, or experimental measurement supplies valid
endpoints. Endpoints equal to the threshold matter: L=t is sufficient for yes,
whereas U=t cannot justify no because P=t remains possible. QED.

**Refinement proposition.** If a second valid interval satisfies
L<=L'<=P<=U'<=U, every previously definite decision remains the same.

**Proof.** Previous yes gives L'>=L>=t; previous no gives U'<=U<t. QED.
A narrower interval need not increase coverage on an arbitrarily chosen finite
threshold set if no threshold crosses a newly excluded portion.

For a threshold drawn uniformly from [0,1], undecided thresholds form (L,U],
whose length is U-L. Thus the hypothetical uniform-threshold coverage is
1-(U-L); equality endpoints have zero measure under that continuous law. This
identity does **not** apply numerically to our deliberately nonuniform finite
threshold set, which oversamples boundaries and reference equality. No uniform
deployment threshold distribution is assumed.

These are elementary consequences of sound interval reasoning and selective
decision-making, not new theorems or a novelty claim. Zero observed decision
errors in the experiment is a finite computational check; the proposition's
general guarantee remains conditional on valid bounds and model scope.

## Actual results

All 32 CLI calls completed, all 32 probability and partition enclosures contained
the independent exact values, and every full-depth interval was exact. Across
248 related threshold observations there were **zero wrong definite decisions**.
This is not an estimate of universal reliability or a calibrated risk bound.

For the six nontrivial families, each configuration has 48 threshold
observations. Removing thresholds 0 and 1 leaves 36 interior observations.
The removal separates easy probability-boundary checks from practical
interior decisions; all original observations remain in the result artifact.

| Configuration | Nontrivial definite / 48 | Coverage | Interior definite / 36 | Interior coverage | Mean nontrivial probability width |
|---|---:|---:|---:|---:|---:|
| Shallow | 6 / 48 | 12.50% | 0 / 36 | 0% | 1 |
| Moderate | 6 / 48 | 12.50% | 0 / 36 | 0% | 1 |
| Enriched | 46 / 48 | 95.83% | 34 / 36 | 94.44% | 0.03139 |
| Full | 48 / 48 | 100% | 36 / 36 | 100% | 0 |

The six definite nontrivial shallow/moderate decisions are simply the boundary
target P>=0. Their enclosures are correct yet uninformative at every selected
interior threshold. This is the central separation between enclosure accuracy
and useful decision support. The negative control's P=0 interval is already
exact at shallow depth, so it correctly rejects every positive threshold.
The positive control has true P=1, but baseline shallow/moderate bounds remain
[0,1]; the enriched witness/lower-mass setting and full enumeration close the
interval to [1,1]. Conservative abstention is not an incorrect rejection.

The enriched setting closes probability width to zero in seven of eight sampled
families, including both controls. The remaining all-H length-10 family at q=2
and contact threshold 2 has exact probability 9304/13323, approximately 0.69834.
Its enriched interval is [9304/15683, 14384/18403], approximately
[0.59325, 0.78161], width 0.18836. It supports the selected low/high threshold
decisions but remains undecided at t=3/4 and t=9304/13323. The latter is a
useful equality stress test: a correct finite-width interval need not prove
P>=the exact true P unless its lower endpoint reaches that value.

### Cost is a separate measurement

| Configuration | Median CLI wall time across eight families | Min–max |
|---|---:|---:|
| Shallow | 0.0664 s | 0.0620–0.0771 s |
| Moderate | 0.0571 s | 0.0541–0.0623 s |
| Enriched | 0.1656 s | 0.1019–0.2995 s |
| Full | 0.0788 s | 0.0597–0.1837 s |

These are single local subprocess measurements including interpreter startup
and scheduling. The apparently faster moderate median is not evidence of a
general depth/runtime relation. At these tiny sizes, complete enumeration was
cheaper in the median than the enriched configuration and answered every
selected threshold. This is a negative cost finding for this sampled enriched
setting, not an asymptotic claim or a hardware-independent advantage. Repeated
budget-matched runs at larger feasible sizes would be needed for a performance
study. No statistical intervals are reported for these hand-selected,
strongly related decisions and one-off timings.

## Artifacts, reproduction, and limitations

Run from the independent SVB project root:

```sh
PYTHONPATH=src python3 -B -m unittest discover -s tests -p test_bound_utility.py -v
PYTHONPATH=src python3 -B -m svb.bound_utility
```

The seven self-contained unit tests passed. They cover inclusive-lower and
strict-upper equality handling, zero/one controls, invalid interval admission,
an intentionally wrong certificate that fails against the exact reference,
valid but useless [0,1] bounds, a complete small rational-grid safety check,
and preservation of decisions under valid refinement. They need no FoldBounds
checkout. The experimental command uses the actual read-only source with `-B`
and explicit `PYTHONDONTWRITEBYTECODE=1`, a minimal credential-free environment,
and SVB as the working directory. Temporary/home data stay under SVB. It has a
90-second per-call timeout and checks a 1 MiB captured-output cap. These are
fixed trusted local commands, not a sandbox for arbitrary submitted programs.
No network, installer, build or subject source modification is used.

`results/v0.3.0/bound_utility.json` retains sanitized per-call reference values,
intervals, widths, decisions, exact oracle classifications, timings, errors,
scope, runtime and subject commit identity. Verbose commands/stdout/stderr are
gitignored in `results/local/bound-utility/raw.json`. The frozen digest is
`results/v0.3.0/bound_utility_protocol.sha256`. Earlier protocols and results
are unchanged. All attempted calls in this study completed; there are no
unreported failed or skipped calls.

The conclusions are limited to these synthetic finite-lattice models and
predeclared hypothetical probability decisions. Small convenience samples,
dependent thresholds, configuration confounding, exact reference costs and
shared runtime/compiler trust limit external validity. The study does not
recheck FoldBounds' Lean theorem sources, establish that Python is formally
refined to Lean, or validate a physical protein model. Similarly, PCS proof
validity within its admitted predicate and trust boundary does not itself
establish that a scientific model or empirical interpretation is adequate.
Enclosure correctness, justified decisions and empirical adequacy remain
separate questions throughout.
