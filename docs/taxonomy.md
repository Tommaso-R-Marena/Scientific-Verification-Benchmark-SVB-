# Scientific verification taxonomy

Evidence sorts are not a total ranking. A mathematical certificate, observation, provenance record and numerical bound establish different propositions. The evaluator never treats a single score as overall scientific truth.

| Dimension | Target question | Pilot failure/control |
|---|---|---|
| Logical/mathematical | Does the precise proposition follow under explicit consistent assumptions? Is the offered proof valid? | quantifier swap, division by zero, stationary point vs global optimum, conditional probability |
| Computational | Does the program implement this finite specification? | units, exact rational arithmetic, archived-data reductions |
| Numerical | Is precision/convergence adequate for the requested equality or tolerance? | binary64 variance cancellation, positive interval-product corner |
| Statistical | Are uncertainty and analysis assumptions justified? | familywise error under explicit independence, covariance, train/test overlap |
| Model adequacy | Does the model describe the intended target under relevant mechanisms? | exact lattice model cannot establish physical protein affinity |
| Empirical | Do independent observations support the physical/generalizing/causal claim? | observational causal nonidentifiability, absent equivalence study, MD trapping alternative |
| Provenance/reproducibility | Are bytes, versions and sources identifiable and computations repeatable? | admitted SHA-256, mismatched hash, fabricated unlinked replication |
| Epistemic sufficiency | Is acceptance, refutation or a narrower conclusion justified? | missing bridge versus refutation, unsupported formal-verification assertion |

Domain is a task-routing category, not an evidence type. A biophysical task may be computationally established, while a mathematical calculation may leave its scientific application unsupported. Refutation names its target: false proposition, invalid supplied proof, incorrect computation or failed provenance assertion. These are distinct failure modes.

Response status is separate from adjudication: unsupported = system disclaims capability; execution_error = system did not complete; missing = no submitted row; insufficient_evidence = completed scientific judgment that supplied evidence does not justify a decision. A malformed batch is rejected at admission rather than partly scored.

The initial dataset does not exhaust these dimensions. It contains no definitive empirically_supported positive, no biological prediction trial, no validated medical judgment, no model-generated language response and no protected hidden set. Schema capacity is not empirical capability coverage.
