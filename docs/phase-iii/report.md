## Concrete improvements

exclusive under their present meanings. It proposes separately versioned typed
fields for target/evidence relation, justification, scope, computational checks,
empirical support, strength rubric and uncertainty. Exact structural and
cross-field semantics are implemented with three historical-case illustrations.
Known collisions are separated representationally; superior scientific usability
or inter-reviewer reliability is not established. The pilot has no dedicated
conflicting-study “both” control or formal proof-checking case, so it cannot
empirically qualify every proposed axis or domain.

The [pilot](pilot.md) selects twelve existing claims in six pairs from five
study families using explicit purposive criteria, before any human judgments but
after known model outcomes. Reference and candidate-review ZIPs omit author
answers and provider envelopes; a shared source archive preserves provenance,
licenses and byte hashes without repeating every source for each stage. Twelve
raw B explanations are retained without repair. Public case mappings remain
reconstructable, so actual blindness is not claimed. The guide, worksheet and
blank forms permit category challenge, multiple defensible labels and inability
to assess. Thirty-six independent reference judgments are planned, down from
132 for the full package; no assignments or consent are fabricated.

The [ingestion pipeline](adjudication_pipeline.md) checks human/coordinator
attestations, consent/assignment declarations, strict data formats, source and
candidate hashes, citations and immutable review rounds. It rejects software
fixtures in production and restricts repository outputs to ignored private
results/local. It retains scientific rationales, proposed revisions, uncertainty,
source exposure and separate error allegations/ambiguity flags. Pairwise set
agreement, Jaccard and carefully qualified nominal kappa calculations expose
missing and selected denominators. These are tested software capabilities, not
observed human agreement. No majority vote creates new gold.

## Methodological findings

A new post-hoc development replay finds 1.5B order consistency of 3/6 exact
categories but 6/6 coarse decisions; all three changes are within the accepting
group. The frozen failed gate remains failed. This qualifies what the earlier
order finding measures, without retrospectively requalifying a model.

An acceptance-membership audit confirms that allowing multiple positive evidence
types leaves historical evidence-present false accepts at 1/6 for 0.5B and 2/6
for 1.5B in both decoding modes. If genuine reviewers disagree across acceptance
membership, a unique false-accept indicator is not identified; fixed-item bounds
and explicit ambiguous strata would be required. No alternative primary scores
or favorable reference edits are introduced.

A separate integer-tenths/cross-product calculation reproduces the checked sleep,
chick and oxygen numerical witnesses. No discrepancy is found in those checked
values. It does not prove original measurement reliability, source completeness,
causal scope or every scientific reference. Scientific claim atomicity,
secondary-source dependence, lexical cues, failed schema qualification and the
lack of calibrated confidence remain substantive limitations.
