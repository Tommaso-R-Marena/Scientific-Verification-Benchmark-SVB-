# Highest-value next research steps

1. External scientific adjudication and a genuinely protected evaluation split. Recruit domain experts to challenge all scope labels and alternative worlds; replace author metadata hints with independently curated evidence packages; freeze a new version before system developers see it. Add correctly supported empirical positives, source-mismatched citations and uncertain/contested scientific questions with adjudication disagreement. Preserve pilot artifacts.
2. Real scientific AI response evaluation. Connect optional model APIs only after budget authorization, use blinded responses and matched tasks with independent coding of reasoning, source attribution and scope. Compare exact-numerical and evidence-gating ablations under prespecified family-level sampling and analysis. The current deterministic policies are controls, not that experiment.
3. Broader scientific and system replication. Have a second lab implement the reference computations, widen biophysical models and parameter uncertainty, benchmark real assay data under licensed provenance, replay relevant Lean proofs and exercise the website DOM locally. Introduce hard sandboxing before accepting executable third-party adapters. Keep capability-specific denominators and model-versus-physical evidence separate.
