kept104.25. The frozen mismatch reference was therefore invalid. PCS correctly
established no attached mathematics. It remains in all18 execution denominators,

into the primary suite or called independent generalization.

S05's age-column challenge was deferred by a lexical unit limitation (`days`).
A separate supported-unit wet/dry-mass control S05b yielded **CONFIRMATION** for
the mean of `dry_mass` while the source literally targets `wet_mass`. The hostile

proposed dry column and204.25g for the literal wet column. This repeatable
controlled binding failure survives correct arithmetic. It is limited by
submitter-trusted vocabulary, not kernel unsoundness; ordinary prose or ambiguous
variable names still require scientific review. Refusing inadmissible aliases or
requiring independent field/custody admission can flag this controlled conflict;
that policy cannot generally prove natural-language meaning.

All three primary mathematical metamorphs (unit conversion, row permutation,
exact-value representation) preserve matches. Source instructions do not create
the tripwire file. These are tests of a data-only verifier, not LLM prompt-injection
resilience. All four public-data cases were mathematically matched but deferred

scientific rejection. No measured source attribution or experimental validity

no production service or interactive browser study was run. The site still
expects the v1 receipt schema, so adopting the existing v2 runner requires an
owner-reviewed compatible integration rather than a file swap assumed safe.
