# Decisions reserved to PCS/SVB owners

No decision below is made by this diagnostic. No merge, deployment, admission,
reviewer contact or prospective study has occurred.

1. **Prospective ClaimCheck:** approve/amend/reject PCS's A1 protocol, A2 criteria,
   A3 queries/contexts and actual access conditions before sampling any new paper.
   This SVB suite is development/diagnostic and cannot stand in for that study.
2. **Human review:** authorize recipients, conflicts/consent, domain/methods
   qualifications, custody/source-admission review and discrepancy adjudication.
   The supplementary packets and Phase III infrastructure are prepared, not
   externally reviewed. No AI agreement substitutes for those people.
3. **Model resources:** authorize access/budget/retention terms for any proposer
   arms. This work uses no model API or private inference credential.
4. **Research runner:** choose whether to adopt the already-proposed strict v2
   runner, amend it or withdraw the original stand-alone download. Validate
   compatibility, canonical grammar, pinning, artifact identity and independent
   replay. The browser currently imports only v1 schema; a coordinated change
   needs separate review. No evaluated-system changes were made here.
5. **PCS source admission/CI:** decide retained-source tags/manifests and required
   checks under existing owner gates. SVB does not bypass or modify those gates.
6. **Public website:** decide source admission, schema/pin integration, protected
   gate changes and any eventual deployment. Only pinned local source was read;
   the production service was not probed.
7. **Scientific source authority:** decide who may attest a variable dictionary,
   file version, population and row-selection provenance. A self-supplied alias,
   data hash or named-reviewer string does not independently authenticate those
   facts. A strict binder can improve refusal while reducing legitimate coverage.
8. **Usability and public interpretation:** approve the actual human study and
   ethics/consent process, including whether users understand that a mismatch is
   not a paper-error accusation and a number confirmation is not empirical truth.

Before further scientific validation, independent reviewers must examine original
methods, not just reconstructed arithmetic, and decide which target interpretations
are defensible. No fixed threshold, novelty or safety superiority is established
by18 related authored controls. The separate future agent-safety benchmark proposal
must evaluate competing architectures fairly, without assuming PCS is preferred.
